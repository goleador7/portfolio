# Goleador Portfolio

A personal developer portfolio for Imad (Goleador) — full-stack developer and founder of Riwaq Dev.

🔗 **Live:** https://goleador-portfolio.vercel.app/

## Features

- 🌗 Alternating light/dark section rhythm for visual pacing
- 🌍 Full trilingual support — English, French, and Arabic, with proper RTL layout for Arabic
- ✍️ Animated rotating hero tagline (typewriter-style, respects `prefers-reduced-motion`)
- 🗂️ Project detail modals with a live embedded browser-mockup preview, tags, features, and links
- 📇 Contact grid with click-to-copy for handles that don't have a direct link (e.g. Discord)
- 📱 Fully responsive across all breakpoints, from small mobile (320px) up through large desktop (2560px+)
- 🍔 Slide-in mobile navigation with overlay, auto-close on link click, and scroll lock while open
- ♿ Accessible by default — visible focus states, aria-live regions, keyboard navigation, reduced-motion support

## Sections

- **Hero** — animated intro with rotating tagline
- **About** — bio, and a categorized skills grid (languages, frameworks, databases, tools, networking, ML)
- **Services** — what Imad builds for clients (web apps, e-commerce, admin dashboards, data/automation, custom software)
- **Projects** — RIWA9 Store (Laravel e-commerce platform) and a Mini ATS System (NLP-based resume screening), each with an in-page detail modal
- **Contact** — Facebook, Instagram, Discord, WhatsApp, Email, and GitHub, all in one language-aware grid

## Tech Stack

`HTML` `CSS` `Vanilla JavaScript`

No frameworks, no build step — plain JS handles language switching, the mobile nav, the rotating tagline, and the project modals.

## Why this project

Built to stand out from typical single-language, static developer portfolios by pairing genuine trilingual support (relevant given Imad's base in Algeria) with small interaction details — like live project previews in-modal and a typewriter hero — that most portfolios skip.
