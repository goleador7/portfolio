# 🎮 Goleador Portfolio — PS4/PS5-Inspired Developer Portfolio

A personal portfolio site with a console-inspired dark, cinematic aesthetic and a Windows File Explorer-style project browser.

🔗 **Live:** https://goleador-portfolio.vercel.app/

## Features
- 🕹️ PS4/PS5-style UI/UX inspiration
- 📁 File Explorer-style navigation for browsing projects
- 🎨 Cinematic dark theme
- 📱 Fully responsive design

## Tech Stack
`HTML` `CSS` `JavaScript`

## Why this project
Designed to stand out from typical developer portfolios — reflecting both my gaming background (Goleador) and my attention to UI/UX detail.S
